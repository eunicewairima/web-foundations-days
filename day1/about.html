About QuickNotes

QuickNotes helps you capture ideas, reminders, and tasks in one simple place. Use it to write down thoughts as they come to you and keep them easy to find.

How to use QuickNotes

  1. Open the Home page and enter a title for your note.
  2. Write your idea or reminder in the note field.
  3. Select “Save note” to add it to your notes.

Features

  • Quickly capture ideas and reminders.
  • Give each note a clear title.
  • Use keyboard shortcuts to work efficiently.

Keyboard shortcuts

Shortcut Action
Ctrl + N Start a new note
Ctrl + S Save the current note
